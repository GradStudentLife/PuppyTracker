PUPPY TRACKER - iPHONE WEB APP

This is a Progressive Web App. It stores puppy events in the browser on the device.

IMPORTANT:
A PWA must be served from HTTPS (or localhost) for service-worker/offline behavior. You cannot reliably open index.html from Files and get the full installable app experience.

EASIEST SETUP:
1. Put these files on a simple HTTPS web host.
2. Open the HTTPS address in Safari on your iPhone.
3. Tap Share.
4. Tap "Add to Home Screen".
5. Open Puppy Tracker from the new Home Screen icon.

The app stores events in localStorage on that iPhone/browser.

FEATURES:
- One-tap Pee, Poop, Potty-Nothing
- Timed Sleep, Crate, Whining
- Meal quantity
- Notes
- Custom categories
- History/search
- Potty intervals
- Average sleep/crate/whining durations
- Pee relative to waking and meals
- Day/night setting
- CSV export

For a future version, the data layer can be upgraded from localStorage to IndexedDB and a proper backup/restore file can be added.
